# I1 handoff

## Done

- Added the role-home model for technician, planner, site HSE supervisor, site lead, and operations manager.
- Added a responsive home screen that composes injected feature widgets and gives each role a next safe action.
- Added site-scope filtering for home-screen data and scoped route context for site users.
- Added responsive home styling for desktop and 375 px layouts, including an always-visible LOTO and isolation safety line.

## How to see it

- Render `src/features/home/index.jsx` from the shell home route and pass `user`, `data`, and the feature widget exports through `widgetComponents`.
- Use the `Home` screen with a site-scoped user such as `{ role: 'site_lead', siteIds: ['S04'] }` to verify that only Arroyo records reach the widgets.

## Tests
