## Limits
Sample quantities/specifications remain illustrative. A min/max setting is per asset/part while physical stock is pooled per site. Suggestions reference current sample zero stock, never invent stockout history. Requests only create through explicit user actions, never every render. Local browser persistence retains existing prototype keys; no backend transactional purchasing or durable multi-user inventory guarantees. Non-integer quantities are rejected rather than rounded. UI financial rank uses historical measured parts-wait exposure; no unsupported lead-time forecast.
