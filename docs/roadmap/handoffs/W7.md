# W7 handoff

## Done
- Searchable activity timeline filtered by type, site, asset, actor and date. Actor, role, timestamp, reason, record ID and evidence/decision metadata remain visible. Filters persist per demo user.
- Site-scoped CSV export for HSE supervisors and operations managers, enforced again in the domain against the signed-in user. CSV contains precisely the permitted filtered rows; embedded quotes/newlines are escaped and spreadsheet formulas are neutralized.
- Global NotificationBell provides an accessible notification dialog, unread count, relevant workspace links and persistent per-user mark-read state.
- Notifications derive from warning events plus known sample stock, unreviewed urgent requests older than four real hours, red pre-dispatch checks, daily sample minimum breaches, supervisor site release and newly overdue severity-5 actions. Acknowledged, false-alarm-reviewed or staged warnings suppress repeat notifications. Warning notifications deduplicate by warning; event notifications by event; daily digests by as-of date.
- Planner minimum overrides are reflected in sample stock digests. Unknown stock does not become a stock-shortage warning.
- Operations managers can open a monthly KPI email preview with historical downtime and a source route. Email and push delivery are explicitly simulated; no external messaging occurs.
- ActivityFeedMini exported from widgets.jsx for homepage/site integration.

Planner gets a daily sample-stock digest and any overdue pending seeded rush request; site lead/manager receive supervisor site-release notices.

## Limits
- Activity UI is append-only/read-only, but localStorage can be edited/reset and the shared activity store retains at most 2,000 entries. The screen accurately describes this as a browser prototype, not an immutable regulated archive.
- HSE overdue reminders use the workbook/replay as-of date; urgent request age uses actual request timestamps. Long-existing overdue actions do not create a new alert every render.
- Monthly preview is requested on screen rather than claiming a background scheduler. Source financial scenario estimates are not reported as realized savings.
- No dependencies, shared contracts, external services or files outside W7 ownership were changed.
